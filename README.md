#### Заметки

Обфускация должна мутировать код так, чтобы код противоречил "соглашение об именновании":

- имена переменных противоречат **snake_case**
- имена переменных должны быть длинными либо слишком короткими, исключая четкие описания
- имена содержащие цифры должны запутать или не иметь смысла
- простые счётчики типа(i,j)

Обфускация должна мутировать код так, чтобы запутать логику работы кода:

- Добавлять лишние циклы(функции), удлинять циклы(функции), диверсифицировать функцию на несколько и т.д.
- уменьшать или увеличивать вычисления
- константы, строки могут объединяться в один массив и использоваться по запутанным индексам

Дополнительно:

- антиотладчик
- удаление комментариев-пояснений(минификация)

### elf-inspector.rs

Внутри файл разбит тремя баннерами на разделы:

     Раздел 1 — расшифровка констант ELF: константы (PT_INTERP, DT_*, STT_FUNC) и функции вида sht_to_str, dt_tag_to_str (бывший dicts.rs);
     Раздел 2 — ядро: ElfInspector, методы разбора и печати всех разделов отчёта, точка расширения function_symbols() (бывший inspector.rs);
     Раздел 3 — точка входа: разбор аргументов, чтение файла, обработка ошибок.

проверки: /bin/ls (заголовок, 14 сегментов, символы, .dynamic), тестовый examples/sample32.elf (символ main = FUNC GLOBAL DEFAULT .text), лимит -n 2, ошибка на не-ELF с кодом возврата 1. Обновил готовый бинарник bin/elf-inspector и пример отчёта examples/report_ls.txt; раздел «Структура кода» в README теперь описывает однофайловую компоновку.


src/
├── main.rs              # точка входа obfuscator-core
├── lib.rs               # pub mod cli; csource; dicts; inspector; obfsource; pipeline;
├── cli.rs               # разбор аргументов (-obf, inspect, -f)
├── dicts.rs             # константы ELF
├── inspector.rs         # инспектор: разбор ELF, кандидаты, JSON

└── bin/

    ├── obfuscator.rs    # автономный обфускатор (C-файл + JSON)
    └── cli.rs           # тонкая обёртка → cli::run (по желанию)
